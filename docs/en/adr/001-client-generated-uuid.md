# ADR-001: Client-generated UUID as the primary key

- **Status:** accepted (lab 2) · PL: [../../pl/adr/001-client-generated-uuid.md](../../pl/adr/001-client-generated-uuid.md)
- **Context:** the lab 2 instruction requires UUID keys generated by the client (not by JPA or the database).
- **Decision:** `@Id private UUID id` without `@GeneratedValue`; the value is assigned by the `UUID.randomUUID()` field initializer (with `@Builder.Default`) at object construction time.
- **Consequences:** Spring Data's `save()` cannot tell a new entity from an existing one (the id is always set) → it picks merge: an extra SELECT before the INSERT. Acceptable in the lab phase; if performance ever matters, the entity can implement `Persistable.isNew()`.
